## Columns that must never be empty

- CIN - Cannot be NULL ,Because this is consider as a unique identifier for every company
- CompanyName - Cannot be NULL, Beacuse it uses to understand the particular company name with CIN no.
- CompanyROCcode - Cannot be NULL, Because it uses to identify which ROC the company belong
- CompanyCategory - Can be NULL
- CompanySubCategory - Can be NULL
- CompanyClass - Can be NULL
- AuthorizedCapital - Can be NULL
- PaidupCapital - Can be NULL 
- CompanyRegistrationdate_date - Cannot be NULL, Because it used to understand when the company got registered
- Registered_Office_Address - Cannot be NULL, Because it used to identify which is the a companies registered office
- Listingstatus - Can be NULL
- CompanyStatus - Cannot be NULL, Because it give the major idea about is the company currently active or not 
- CompanyStateCode - Cannot be NULL, Because it gives which statecode it belong
- CompanyIndian_Foreign Company - Can be NULL
- nic_code - Can be NULL
- CompanyIndustrialClassification - Can be NULL
